# 취향저격 OTT 추천 알고리즘 서비스 구현 계획

이 프로젝트는 사용자의 세부적인 취향(선호 장르, 보고 싶은 분위기, 이용 중인 OTT 플랫폼, 러닝타임)을 입력받고, 맞춤형 평가 데이터를 결합하여 **개인 맞춤형 OTT 콘텐츠를 정교하게 추천해주는 브라우저 기반 웹 서비스**입니다. Next.js 16 및 TailwindCSS v4를 활용하여 한 편의 영화관 또는 넷플릭스 인터페이스를 연상시키는 고품격 다크 모드 UI와 실시간 추천 알고리즘을 구현합니다.

## User Review Required

> [!IMPORTANT]
> **핵심 아키텍처 및 연동 방식 제안**
> 1. **순수 프론트엔드 단일 페이지 웹앱(SPA)**: 서버/DB를 배포하지 않고 브라우저 내 `localStorage`를 활용하여 새로고침 시에도 모든 데이터(평가 점수, 좋아요/싫어요 목록, 북마크, 선호 장르)를 유지합니다.
> 2. **브랜드 테마 연동**: 넷플릭스, 티빙, 웨이브, 디즈니플러스, 왓챠 등 실제 OTT 브랜드의 시그니처 컬러를 적용한 동적 계정 연동(가상) 및 필터링 시스템을 탑재합니다.
> 3. **비주얼 에스테틱**: 단순 텍스트 나열을 지양하고, 영화별 특징에 따른 **초고화질 CSS 그라데이션 포스터** 및 **반투명 글래스모피즘(Glassmorphism)** 레이아웃을 통해 세련되고 프리미엄한 사용자 경험을 연출합니다.

---

## Proposed Changes

프로젝트를 크게 4가지 컴포넌트로 나누어 개발합니다.

### 1. 콘텐츠 데이터 허브 (`app/data/contents.ts`) [NEW]
사용자 추천의 밑바탕이 되는 **30개 이상의 엄선된 하이엔드 콘텐츠 데이터베이스**를 구축합니다.
- **영화 및 시리즈**: 액션, 로맨스, 코미디, 스릴러, 드라마, 다큐멘터리, SF, 애니메이션 등 다양한 장르 분포.
- **메타데이터 속성**: 
  - `id`: 고유 식별자
  - `title`: 콘텐츠 제목
  - `type`: 영화(movie) 또는 시리즈(show)
  - `genres`: 복수 장르 리스트 (예: `["스릴러", "드라마"]`)
  - `moods`: 감정 및 분위기 태그 (예: `["긴장감 있는", "몰입감 있는"]`)
  - `platforms`: 제공 OTT 플랫폼 (예: `["Netflix", "Watcha"]`)
  - `rating`: 평점 (1.0 ~ 5.0)
  - `runtime`: 러닝타임 (분 단위)
  - `releaseYear`: 개봉 연도
  - `summary`: 시놉시스 줄거리
  - `cast`: 출연 배우 및 감독 정보
  - `posterGradient`: 영화의 감성에 맞춤 매칭된 비주얼 CSS 그라데이션 테마 (썸네일 대용)
- **스타터 평가 셋트**: 사용자가 처음에 취향 분석을 위해 평가할 3개의 대표 콘텐츠 선정.

### 2. 추천 점수 계산 엔진 (`app/utils/algorithm.ts`) [NEW]
PRD에서 정의한 가중치 배점 기준에 따른 **정교한 매칭 알고리즘**을 구현합니다.
- **장르 일치 (최대 30점)**: 선택한 선호 장르 개수 비례 점수 부여.
- **분위기/기분 일치 (최대 25점)**: 선택한 시청 분위기 태그 일치 시 점수 부여.
- **OTT 플랫폼 일치 (최대 20점)**: 사용자가 가입/연동한 플랫폼 내 시청 가능 시 점수 부여.
- **콘텐츠 자체 평점 (최대 15점)**: 기본 평점에 비례한 점수 (예: 평점 5.0 = 15점).
- **피드백 및 스타터 평점 반영 (최대 10점)**: 
  - 사용자가 좋아요를 누른 콘텐츠와 장르/분위기가 겹치는 콘텐츠에 가중치 부여.
  - 싫어요를 누른 콘텐츠와 겹치는 콘텐츠는 감점 처리.
  - 스타터 평가에서 높은 별점(3점 이상)을 준 항목의 특징을 추출해 플러스 요인으로 작동.
- **동점자 처리**: 점수가 같을 경우 자체 평점이 높은 작품을 우선 정렬.
- **매칭 근거 추출**: 추천 카드의 '추천 이유'에 일치도가 높은 항목을 서술형 문장으로 구성 (예: *"선호하시는 [스릴러] 장르이며, 구독 중인 [Netflix]에서 시청 가능합니다."*)

### 3. 스타일 시스템 (`app/globals.css`) [MODIFY]
OTT 특유의 깊이 있는 감성을 살리기 위한 고품격 CSS 스타일 시스템을 구현합니다.
- 네온 레드 및 골드 포인트 컬러 정의.
- 글래스모피즘 효과 (`backdrop-blur-md`, 반투명 다크 그레이 배경).
- 버튼 마우스 오버 시 번지는 글로우(Glow) 효과 및 슬라이드 트랜지션.
- 메인 화면 그라데이션 및 반응형 카드 레이아웃 스타일.

### 4. SPA 앱 메인화면 (`app/page.tsx`) [MODIFY]
반응형 레이아웃과 함께, 탭 상태 전환을 통해 끊김 없는 매끄러운 단일 페이지 웹앱을 구현합니다.

#### 1) Landing View (메인 화면)
- 어두운 시네마 극장의 느낌을 주는 백그라운드 영상 스타일 그래픽.
- 로고 "취향저격" 네온 타이포그래피.
- "나의 취향 분석하고 추천 받기" 초대형 입체 글로우 버튼.

#### 2) Login & OTT Sync View (로그인 및 연동 페이지)
- 가상 로그인 인터페이스(아이디, 비번 입력) 구현.
- **OTT 연동 섹션**: 넷플릭스(네온 레드), 디즈니플러스(딥 네이비), 쿠팡플레이(스카이 블루), 티빙(크림슨 레드), 웨이브(오션 블루) 등 브랜드 로고 컬러와 홉 효과를 구현한 연동 토글 버튼 배치. 클릭 시 즉시 구독 플랫폼 상태가 변경됨.

#### 3) Starter Taste Profiler View (스타터 3대 작품 평가)
- 사용자 취향의 영점을 맞추기 위해, 서로 다른 성격의 대표작 3개를 제공.
- 각 카드에 대해 1~5점의 별점을 주는 별점 위젯.
- **동적 피드백 수집**:
  - 3점 이상 선택 시: *"이 작품의 어떤 점이 좋으셨나요?"* 문구와 함께 [배우], [장르], [감독] 다중 선택 칩 등장.
  - 3점 미만 선택 시: *"이 작품의 어떤 점이 아쉬우셨나요?"* 문구와 함께 [배우], [장르], [감독] 다중 선택 칩 등장.
- **종합 설정 패널**: 오늘 보고 싶은 기분(가볍게, 몰입감 등), 선호 장르 체크박스, 선호 러닝타임 필터 제공.

#### 4) Recommendation Dashboard View (추천 대시보드)
- 계산된 매칭률(예: **98% 매칭!**)과 추천 사유를 시각화한 콘텐츠 카드 리스트 배치.
- 랭킹 순 정렬 및 카테고리 필터바 (전체, 넷플릭스작, 티빙작, 스릴러 장르 등 즉시 필터링).
- 카드를 클릭하면 상세 정보를 품은 슬릭한 모달 팝업이 등장 (배우진, 상세 시놉시스, 유사 작품 추천).
- 각 카드에는 **[좋아요 / 싫어요 / 보관함 저장]** 기능 내장. 좋아요 누르면 알고리즘이 실시간 재계산되어 즉시 피드백이 순위에 반영됨!

#### 5) Library & Preference Center View (보관함 및 취향 리포트)
- 사용자가 보관(저장)해둔 콘텐츠 목록을 한눈에 격자형 카드로 감상.
- **나의 취향 분석 리포트**: 
  - 내가 가장 좋아하는 장르 TOP 3 (Recharts 도넛 차트 또는 게이지 바 시각화).
  - 선호하는 시청 분위기 및 나의 연동 OTT 플랫폼 현황 차트.
  - 서비스 데이터 전체 초기화 기능 제공.

## Verification Plan

### 수동 및 시각적 검증
1. **반응형 테스트**: Chrome 개발자 도구의 Mobile 모드에서 입력 폼 및 카드 레이아웃이 정상적으로 줄어드는지 확인.
2. **알고리즘 정합성 검증**:
   - 스릴러 장르와 넷플릭스를 선택했을 때 넷플릭스 스릴러 영화들의 점수가 상위로 올라가는지 확인.
   - 특정 콘텐츠에 '좋아요' 피드백을 주었을 때, 유사 장르/분위기를 가진 다른 콘텐츠의 매칭 점수가 실시간으로 상승하여 최상위권으로 배치되는지 검증.
3. **데이터 유지 검증**: 추천 조건을 고르고 몇 개 콘텐츠를 저장한 뒤 새로고침을 실행했을 때, 이전에 체크된 설정과 보관함 목록이 그대로 유지되는지 확인.

### 자동화 빌드 검증
- `npm run build`를 실행하여 Next.js TypeScript 컴파일 및 린트 오류가 없는지 사전 빌드 단계를 수행합니다.
